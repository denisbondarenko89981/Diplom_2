#  Stellar Burgers API Tests

Автоматизированные тесты для проверки REST API сервиса **Stellar Burgers**  
Проект написан на **Python + Pytest + Allure** и покрывает основные пользовательские сценарии.

---

## 🚀 Что тестируется

### 🔹 Регистрация пользователя (3 теста)
- Создание нового уникального пользователя  
- Попытка регистрации уже существующего пользователя  
- Регистрация без обязательного поля

### 🔹 Авторизация (2 теста)
- Успешный вход под существующим пользователем  
- Вход с неверными данными

### 🔹 Создание заказов (5 тестов)
- Создание заказа с авторизацией и ингредиентами  
- Создание заказа без авторизации  
- Создание заказа без ингредиентов  
- Создание заказа с неверным хешем ингредиента  
- Создание заказа с одним ингредиентом  

Всего реализовано **10 тестов**.

---

## ⚙️ Технологии

- **Python 3.10+**
- **Pytest** — тестовый фреймворк  
- **Requests** — HTTP-запросы к API  
- **Allure-pytest** — формирование красивого отчёта с шагами и результатами  
- **GitHub + CI/CD** — для хранения и прогонки тестов

## 🧰 Установка окружения

Клонируй репозиторий:
```shell
git clone https://github.com/<твоя_ссылка>/stellar-burgers-api-tests.git
cd stellar-burgers-api-tests
```

Установи зависимости:
```shell
pip install -r requirements.txt
```

▶️ Запуск тестов
Запуск всех тестов:
```shell
pytest
```

Создание отчёта Allure:
```shell
pytest --alluredir=allure-results
```

Просмотр отчёта в браузере:
```shell
allure serve allure-results
```

🧹 Чтобы отчёт был свежим, перед запуском можно очистить старые результаты:
```shell
Remove-Item -Recurse -Force allure-results
```
